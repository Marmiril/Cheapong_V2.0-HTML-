# Cheapong

Cheapong es un minijuego arcade inspirado en Pong, desarrollado con HTML, CSS y JavaScript vanilla.

El proyecto nace como una adaptación web de Evolupong, una versión previa creada en JavaFX. Esta versión está pensada para ejecutarse directamente en navegador e integrarse dentro de un portfolio personal.

## Tecnologías

- HTML5
- CSS3
- JavaScript vanilla
- Canvas 2D

## Características previstas

- Juego tipo Pong 2D
- Jugador contra CPU
- Movimiento con teclado
- Sistema de puntuación
- Estados de juego
- Sonidos
- Efectos visuales
- Integración en portfolio

## Controles

- `SPACE`: iniciar / sacar / reiniciar
- `LEFT`: mover pala a la izquierda
- `RIGHT`: mover pala a la derecha
- `UP`: aplicar efecto
- `DOWN`: modificar efecto / bloquear movimiento
- `ESC`: volver al menú

## Estado

Proyecto en desarrollo.

# Cheapong

Cheapong is an arcade minigame inspired by Pong, developed with HTML, CSS, and vanilla JavaScript.

The project is based on Evolupong, a previous JavaFX version. This web version is designed to run directly in the browser and be integrated into a personal portfolio.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas 2D

## Planned Features

- 2D Pong-style gameplay
- Player vs CPU
- Keyboard controls
- Score system
- Game states
- Sounds
- Visual effects
- Portfolio integration

## Controls

- `SPACE`: start / serve / restart
- `LEFT`: move paddle left
- `RIGHT`: move paddle right
- `UP`: apply effect
- `DOWN`: modify effect / block movement
- `ESC`: return to menu

Work in progress.
